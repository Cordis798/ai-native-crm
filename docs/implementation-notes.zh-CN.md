# 运行模式与实现边界

在线演示、源码实现和真实集成分别验证。阅读能力介绍时，可按下表定位对应证据。

| 范围 | 当前实现与验证方式 |
| --- | --- |
| 在线演示 | 独立静态页面，使用合成 CRM 数据与脱敏历史录制；常规操作在浏览器中模拟，不接入模型、数据库和真实消息渠道。 |
| 完整应用 | Next.js、PostgreSQL、Agent Worker 和调度独立运行；需配置开发环境及相应服务后验证完整业务路径。 |
| 工作台与人工决策 | 不同工具与入口有各自的批准和执行链。普通工作台存在人工决策界面，并不表示所有对外发送路径都已闭合。 |
| 持久化与恢复 | Run、事件、检查点和队列租约提供执行恢复；租约前置检查不等同于全部业务写入都具有原子 fence，也不保证远端动作 exactly-once。 |
| 知识与记忆 | SQL 保存人工确认的客户事实；Mem0 提供可选投影和排序。知识版本与引用不构成报价批准。 |
| 协作渠道 | WhatsApp 服务客户沟通；飞书服务内部协作。企业应用身份、真实收发与任务续跑需在目标环境单独联调。 |
| 评测 | 确定性检查、语义 Judge 与人工复核有不同职责；历史单次评分不能作为业务收益或提升比例。 |
| 可观测性 | Langfuse 只接收经过投影边界处理的数据；Sentry 默认关闭，显式填写安装者自己的 DSN 后才启用。 |

实现入口见主 [README](../README.md)，数据库和浏览器测试分别位于 [tests/invariants](../tests/invariants) 与 [tests/e2e](../tests/e2e)。历史测试记录保留其原始时间和环境，不自动代表当前生产状态。
